# Hermes Monorepo

Single workspace for the Hermes UI / Cortex site.

## Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS + shadcn/ui
- pnpm workspaces

## Apps
- `apps/web` — the Next.js app (4 pages: /, /command-center, /apex, /usage)

## Development
```bash
nvm use
pnpm install
pnpm dev
```

Open http://localhost:3000
